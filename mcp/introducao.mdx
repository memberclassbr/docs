O servidor MCP da Yeon permite que um agente de IA — como o Claude Code — consulte e gerencie um projeto seu: catálogo, vendas, assinaturas, webhooks, afiliados, co-produção, membros e financeiro.

São **94 ferramentas**, uma para cada operação da [API pública](/api/introducao).

## Como funciona

O servidor é um endereço da API da Yeon. Você o registra no seu cliente, entra com a sua conta e autoriza o acesso — como ao entrar num site com outra conta.

```text
você  →  agente  →  https://api.yeon.com.br/mcp
```

Não há nada para baixar, instalar ou atualizar, e nenhuma chave para colar.

O acesso vale para **um projeto**, com as permissões que você aprovou. Você desfaz quando quiser, em **Aplicativos**, no Painel.

## O que dá para fazer

| grupo | exemplos |
| --- | --- |
| Catálogo | criar produto, criar oferta, editar tema, configurar order bumps |
| Vendas | listar transações, detalhar uma venda, consultar clientes, ver indicadores |
| Assinaturas | consultar, cancelar, cobrar agora, reemitir fatura Pix |
| Reembolsos | devolver uma venda, uma linha ou uma cobrança |
| Financeiro | liberações previstas e solicitação de saque |
| Disputas | consultar, enviar evidências, aceitar |
| Webhooks | cadastrar, testar, ver entregas, reenviar |
| Membros | listar, convidar, alterar permissões, remover acesso |
| Afiliados | programa do produto, aprovar, percentuais, aderir |
| Co-produção | convidar, aceitar, percentuais, rendimentos |
| Cupons | criar, editar, excluir |

A lista completa está em [Grupos de ferramentas](/mcp/grupos).

## O que não dá

| | onde fazer |
| --- | --- |
| criar, listar ou trocar de projeto | Painel |
| gerar ou revogar tokens de API | Painel |
| perfil, dados bancários, KYC | Painel |
| Bling, Nuvemshop, pixels, área de membros | Painel |
| aceitar convite em nome de outra pessoa | quem foi convidado, pelo link do e-mail |
| consultar saldo e extrato da conta | Painel |

Um servidor opera em **um projeto**. Para dois projetos, registre duas conexões com tokens diferentes.
