---
title: "Conectar"
description: "Ligar o Claude ao seu projeto da Yeon"
---

Não há nada para baixar nem chave para colar. Você conecta pelo próprio aplicativo e autoriza o acesso numa página da Yeon.

## No Claude (app, site e Cowork)

1. Abra **Conectores** e escolha adicionar um conector personalizado.
2. Cole o endereço:

```text
https://api.yeon.com.br/mcp
```

3. Deixe os campos avançados em branco e confirme.
4. O Claude leva você a uma página da Yeon. Entre com a sua conta.
5. Confira o projeto e as permissões, e clique em **Autorizar**.

Pronto. As ferramentas aparecem na conversa.

## No Claude Code

```bash
claude mcp add --transport http yeon https://api.yeon.com.br/mcp
```

O navegador abre na mesma página de autorização.

Para usar uma [chave de API](/api/introducao) em vez de autorizar pelo navegador:

```bash
claude mcp add --transport http yeon \
  "https://api.yeon.com.br/mcp" \
  --header "Authorization: Bearer $YEON_API_TOKEN"
```

<Warning>
  Passe a chave por variável de ambiente, nunca escrita em arquivo versionado.
  Se vazar, revogue no Painel e gere outra.
</Warning>

## A tela de autorização

Ela mostra:

| | |
| --- | --- |
| **Projeto** | a que projeto o acesso vale. Com mais de um, você escolhe |
| **Permissões** | o que o aplicativo vai poder fazer, em português |

O acesso vale para **um projeto**. Para dois, autorize duas vezes.

Permissões que movem dinheiro ou dão acesso a outras pessoas — reembolso, saque e gestão de equipe — **não entram por padrão**.

## Conferir

```bash
claude mcp list     # yeon: ... - ✔ Connected
```

No Claude Code, `/mcp` lista as ferramentas carregadas. Peça algo simples para confirmar: *"lista os produtos do meu projeto"*.

## Desconectar

No [Painel](https://app.yeon.com.br), em **Aplicativos**, clique em **Desconectar**. O acesso acaba na hora.

Para remover também do cliente:

```bash
claude mcp remove yeon
```

## Problemas comuns

| mensagem | o que fazer |
| --- | --- |
| `Aplicativo não reconhecido` | deixe os campos avançados de OAuth em branco e conecte de novo |
| `Escolha o projeto` | entre no Painel, selecione um projeto e tente de novo |
| `API_TOKEN_SCOPE_MISSING` | a permissão não foi autorizada; desconecte em **Aplicativos** e autorize de novo |
| `429` | limite de requisições; espere os segundos indicados |
| uma ferramenta não aparece | a permissão correspondente não foi autorizada |
