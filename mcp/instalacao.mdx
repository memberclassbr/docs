title: "Instalar e conectar"
description: "Baixar o servidor, configurar e registrar no Claude Code"
---

## 1. Baixar

Pegue o arquivo da sua plataforma em [Releases](https://github.com/memberclassbr/yeon-backend/releases?q=mcp):

| sistema | arquivo |
| --- | --- |
| macOS (Apple Silicon) | `yeon-mcp-darwin-arm64.tar.gz` |
| macOS (Intel) | `yeon-mcp-darwin-amd64.tar.gz` |
| Linux (x86-64) | `yeon-mcp-linux-amd64.tar.gz` |
| Linux (ARM) | `yeon-mcp-linux-arm64.tar.gz` |
| Windows | `yeon-mcp-windows-amd64.zip` |

```bash
tar -xzf yeon-mcp-darwin-arm64.tar.gz
sha256sum -c SHA256SUMS
```

<Note>
  **macOS:** na primeira execução o sistema bloqueia o arquivo baixado. Libere com:

  ```bash
  xattr -d com.apple.quarantine yeon-mcp-darwin-arm64
  ```
</Note>

## 2. Gerar o token

No [Painel](https://app.yeon.com.br), em **Configurações do projeto → Chaves de API**, gere um token com as permissões que você vai usar.

As permissões são definidas na criação e não mudam depois. Para mudar, gere outro token. Veja [Permissões da chave](/api/permissoes).

## 3. Registrar no Claude Code

```bash
claude mcp add yeon \
  --scope local \
  --env YEON_API_TOKEN="$YEON_API_TOKEN" \
  --env YEON_MCP_GROUPS=catalog,sales \
  -- /caminho/absoluto/para/yeon-mcp-darwin-arm64
```

### Variáveis

| variável | obrigatória | valor |
| --- | --- | --- |
| `YEON_API_TOKEN` | sim | o token gerado no Painel |
| `YEON_MCP_GROUPS` | sim | [grupos](/mcp/grupos) separados por vírgula, ou `all` |
| `YEON_MCP_READONLY` | não | `true` carrega só as ferramentas de consulta |
| `YEON_MCP_TIMEOUT_SECONDS` | não | padrão `30` |

<Warning>
  Passe o token por variável de ambiente, nunca escrito em arquivo versionado.
  Se vazar, revogue no Painel e gere outro.
</Warning>

### Escopo

| escopo | disponível |
| --- | --- |
| `local` | só para você, neste projeto (padrão) |
| `project` | versionado em `.mcp.json`, para o time |
| `user` | para você, em qualquer projeto |

O escopo é do seu cliente. O projeto da Yeon vem do token, em qualquer diretório.

## 4. Conferir

```bash
claude mcp list     # yeon: ... - ✔ Connected
claude mcp get yeon
```

No Claude Code, `/mcp` lista as ferramentas carregadas.

Peça algo simples para confirmar: *"lista os produtos do meu projeto"*.

## Trocar o token

Edite a configuração e reconecte. Não há como trocar em execução.

```bash
claude mcp remove yeon --scope local
```

## Problemas comuns

| mensagem | o que fazer |
| --- | --- |
| `Failed to connect` | confira o caminho do binário; rode-o no terminal para ver o erro |
| `YEON_MCP_GROUPS é obrigatório` | informe os grupos |
| `API_TOKEN_INVALID` | token errado ou revogado; gere outro |
| `API_TOKEN_SCOPE_MISSING` | o token não tem essa permissão; gere outro com ela |
| `429` | limite de requisições; espere os segundos indicados |
| uma ferramenta sumiu | o grupo saiu de `YEON_MCP_GROUPS` ou `YEON_MCP_READONLY` está ligado |
